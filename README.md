# Boutique Listing AI

Mobile-first PWA for boutique and vintage resale inventory.

Take or upload item photos, then generate product titles, pricing, descriptions, marketplace copy, Etsy copy, Instagram captions, tags, measurements needed, and condition notes.

## Stack

Next.js App Router, React, TypeScript, Tailwind CSS, Vercel-ready PWA, and AI SDK-compatible vision analysis.

## Run locally

npm install
cp .env.example .env.local
npm run dev

## iPhone install

Deploy to Vercel, open the URL in Safari, tap Share, then Add to Home Screen.
